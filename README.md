# 苟在仙界成大佬 · 世界地图集

27 幅非官方地图，按七个主要活动世界分组。依据小说地理描写整理，原文来源可在查看页底部展开。缺乏大致定位的地点不设假位置，粗略图形的说明放在星号底注。

用 GitHub Pages 从 main 分支根目录发布即可。不需要安装依赖、执行构建或运行服务器。地图修改时重新导出并上传；没有地图更新时无需日常维护。

HTML、CSS、JavaScript 和地图资产均为静态文件。默认载入预览图，缩放时切换原像素尺寸高清图；可单独打开高清 WebP、SVG 和下载 Azgaar 原生 MAP 工程。WebP 为原图压缩版本，本地完整图集另保留 PNG 原件。
